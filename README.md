# read-one

纯本地隐蔽阅读器，支持 txt / epub / mobi。可选听书、本地视频小窗、B 站小窗，以及自备密钥的 AI 助手。无登录、无会员，进度和书库都跟程序放在一起，整夹搬走也能续读。

**当前版本：2.0.0**

## 下载说明

发行内容分成两部分：

- **正式版**：主程序本身，日常使用与后续更新通常只要这一份
- **依赖包**：仅在本机缺少运行环境时需要；装好后一般可删，换机或重装系统再下

Releases 里对应两个压缩包：主包体积较小；依赖包较大，只给首次缺环境的人用。

## 环境要求

- Windows（32 位程序，可在 64 位系统上运行）
- 系统需具备 **.NET Framework 4.7.2**（或更高兼容版本）。多数较新的 Windows 已自带；若没有，用本仓库「依赖包」安装即可
- **听书**：依赖 Windows 自带的语音朗读能力；若本机未装语音，听书可能不可用
- **B 站小窗**：需要本机已安装 Microsoft Edge 的 WebView2 运行时（很多电脑随 Edge 已具备；若打不开小窗，按提示安装即可）
- **本地视频**：主要播 mp4，依赖系统已有的解码能力；个别特殊编码可能播不了
- **AI 助手**：需自行准备 DeepSeek 密钥，并允许联网（可走设置里的代理）
- 本地阅读、书架、书签等不依赖网络

## 首次安装

1. 下载并解压 **正式版**
2. 优先运行正式版里的 `Start.bat`（会先检查运行环境）
3. 若提示缺少运行环境，再下载解压 **依赖包**，运行其中的 `Install-Runtime.bat`
4. 装好后重新运行正式版的 `Start.bat`

说明：

- 建议默认用 `Start.bat` 启动，不要一上来只双击 exe（缺环境时可能来不及提示）
- 同一台机器装过依赖包之后，以后更新一般只换正式版即可
- 依赖包装成功后可以删掉，需要时再重新下载

## 后续更新

- 通常只需重新下载正式版并覆盖程序文件
- 保留你自己的书库、阅读进度和设置，不要用空包覆盖个人数据目录里的这些内容
- 不必每次都带依赖包

## 基本用法

- 主窗口无边框，默认置顶；**右键**打开菜单完成大部分操作
- 打开一本书后即可阅读；听书、B 站、本地视频、AI 等都在右键菜单对应分组里
- 老板键默认 **Alt+S**，可一键藏窗再一键恢复

---

## 本地阅读

- 支持打开 txt、epub、mobi。右键「打开文本 → 新文件」选书即可开始读
- 「打开文本」菜单下会列出最近打开过的几本书，点一下就能续上
- 启动后会自动回到上次读到的位置；阅读中也会定时记住进度，关掉再开不用自己找页
- 默认多行显示，文字随窗口宽度自动折行，上下翻页。右键「多行模式 / 单行模式」可切换；单行时一行横排，超宽用左右键滚
- 默认用 W / S / A / D 上下左右翻页（可在设置「功能键」里改）。Alt+N 可翻一页（听书进行中此键无效）
- 设置里勾选「鼠标滚轮翻页」后，多行模式可用滚轮翻
- 右键「窗口 → 滚动播放[无声]」或热键 Alt+Z，可以无声自动往下翻；速度在设置「功能键」里调
- 若勾选「自动播放/听书结束时打开同目录下一本」，读完或听完一本后会按文件名接着开下一本
- 按住正文区域拖动即可移动主窗口；右下角可拖动手柄改大小（需在设置中开启自由改大小）

## 书架与最近阅读

- 右键「书架」：浏览程序旁边书库文件夹里扫到的书，选中后点「打开」或双击进入
- 右键「最近阅读」：只看最近读过的书，同样打开或双击
- 书架窗口里可「刷新」列表，也可「移除记录」清掉不想看到的条目

## 书签

- 右键「书签 → 添加书签」：在当前阅读位置记一笔，并带一小段摘录方便辨认
- 右键「书签 → 书签列表」：可跳转到该书签位置，或删除；也可跳到其他书上的书签

## 目录与本章

- 打开书籍后会自动识别「第×章」一类标题，生成目录
- 右键「目录」选中章节点「跳转」，可直达该章
- 右键「本章」可只看当前章全文，支持搜索上一条/下一条；双击某一行或按 Enter，会跳回阅读窗对应位置

## 外观与排版

- 右键「系统 → 主题」可选日间、夜间、护眼；设置页里也有同样入口
- 右键「系统」下可直接增大/减小字号和行距
- 设置「样式」里可改背景色与背景透明度、字色、高亮色、字体、是否加粗、字号与文字透明度
- 设置里还可调窗口宽高、缩进、行距、段距（段距可做成段落之间空一行）
- 设置底栏「恢复默认」可一键回到出厂外观和通用选项

## 文本编码

- 打开 txt 时会尽量自动判断编码，减少乱码
- 若仍有乱码，右键「选择编码重载」，可换一种编码重新加载当前 txt

## 听书

- 右键「听书 → 开始/停止朗读」或热键 Alt+V：用本机语音读当前屏幕上的文字，读完自动翻下一屏；本章读完会进同书下一章
- 右键「听书 → 暂停/继续」或热键 Alt+P：在停下的地方接着听，不会整屏重来
- 右键「听书 → 语速加快 / 减慢」，或在设置「功能键」里拖阅读速度条
- 「听书 → 定时关闭」可选关闭 / 15 / 30 / 60 分钟，到点自动停朗读，避免忘记外放；下次开听书会沿用上次选择
- 听书时你仍可手动翻页或滚轮浏览，只改眼前显示，不会打断朗读；自动翻页仍跟朗读位置走
- 读到书末会提示本次阅读已经结束

## 听书操作台

- 右键「听书 → 打开操作台 / 关闭操作台」：弹出一条独立透明工具条，不必反复开主窗菜单；关掉操作台不会停止听书
- 操作台上有语速加减、上一行、下一行；中间键未听书时是开始播放，听书中是暂停/继续
- 与主窗「移开藏字」同一套规则：鼠标移出一段时间后工具条会藏起来，移入（若设置了热键还需按住）再显示
- 老板键藏主窗时操作台一并藏起，但听书不停；藏窗后 Alt+V / Alt+P 仍可用

## B站小窗

- 右键「B站 → 打开小窗 / 关闭小窗」：另开一个置顶、可缩得很小的窗口看 B 站，可登录；Esc、顶条关闭钮或小窗右键「关闭小窗」都能关
- 「B站 → 首页」打开站点首页
- 「稍后再看」「历史记录」：鼠标悬停只刷新菜单列表、不弹窗；点进去可打开列表页或点标题播视频（需已在小窗登录）
- 小窗顶条右键「粘贴并打开」，或在小窗内 Ctrl+V，可粘贴链接直接播
- 设置「通用」里可切换整体缩小 / 原尺寸排版，以及拖动快捷键（默认常为 Alt）：按住该键可在窗口任意位置拖动，且不会点到网页；未按键时只能拖顶部细条
- 双击顶条可恢复小窗默认大小
- 老板键隐藏时会暂停播放；再显示出来不会自动接着播，需自己点播

## 本地视频

- 右键「本地视频 → 打开小窗 / 关闭小窗 / 选择目录」：选一个文件夹，把里面的视频（主要是 mp4，也认部分其他常见格式）按文件名排成列表连播
- 窗口尽量只留画面：左键点击画面播放或暂停，空格同样有效，Esc 关闭
- 鼠标移到窗口底部会出现半透明进度条和当前时间 / 总时长，移开或过几秒会自动藏起
- 画面右键可：播放/暂停、上一集、下一集、选择目录、播放列表、关闭小窗
- 拖动方式与 B 站小窗相同：按住设置里的拖动快捷键再按左键拖
- 双击画面可恢复默认窗口大小；一集播完自动下一集，到列表末尾停住
- 老板键隐藏时暂停；恢复显示后不自动续播

## AI 助手

- 需自行在设置里填写 DeepSeek 的密钥后才能用
- 右键「AI 助手 → 进入/退出 AI 模式」：在阅读窗里用上下两行做隐蔽对话，上行是回复，下行是输入；模式内 Esc 退出
- 输入框按 Enter 发送；右键「新对话」或模式内快捷键可开新会话、清空上下文
- 「切换联网搜索」可开或关网页检索；设置「AI 助手」页可改模型、深度思考、人设预设、联网等
- 人设可选用内置预设，也可自己新建、编辑、删除、复制
- 若配置了代理，AI 请求会走设置里的代理
- 老板键隐藏时会取消正在进行的 AI 请求；打开书籍时会退出 AI 模式，避免状态错乱

## 老板键与隐蔽

- 默认 Alt+S（可在功能键里改）：一键隐藏主窗及伴生小窗。B站、本地视频会暂停；听书操作台跟着藏，听书本身不停。再按一次恢复
- 设置「通用」可开「移开藏字」：鼠标移出只藏正文，窗口仍可点中；可要求移入时按住指定键才显示正文
- 「鼠标双击」隐藏：双击主窗相当于按老板键
- 「闲置超时」只会改标题提示，不会遮住正文
- 右键「窗口 → 窗口置顶」可始终置顶；置顶时一般不显示任务栏按钮，避免点任务栏后不好恢复
- 可开托盘图标：双击显示主窗，右键可进设置、关于、退出；也可隐藏任务栏按钮（通常需配合托盘）
- 「防截屏」可降低被截屏采集的概率（与过高透明可能冲突，改完或需重启）
- 设置「高级」里可改窗口标题和图标，用来伪装
- 若程序已在运行却再次打开，会提示可能被老板键藏住了；被系统最小化时也会转成老板键那种隐藏，按一次即可恢复

## 扬声器静音

- 设置「通用」里默认开启：听书、打开 B 站小窗或本地视频时，对你指定的扬声器做静音，减轻外放风险；耳机等其他设备一般不受影响
- 可选手动指定设备，或让程序自动识别；关掉该选项并保存后，会立刻恢复本程序改过的静音

## 设置与关于

- 右键「系统 → 设置」：样式、通用、功能键、高级、AI 助手
- 功能键页可改：上下左右、老板键、自动播放、听书、朗读暂停、下一页，以及自动播放速度、听书语速
- 右键「系统 → 关于」，或托盘「关于」：查看版本与说明
- 设置底栏：恢复默认、确定、取消
