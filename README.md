# read-one

纯本地隐蔽阅读器（支持 txt / epub / mobi），可选 DeepSeek AI 助手与 B 站小窗。

**当前版本：1.0.7**

## 仓库内容

- `正式版/`：主包，本体控制在 10 MB 内  
- `依赖包/`：.NET Framework 4.7.2 离线安装包 + 一键安装脚本  

## 下载建议

- **第一次安装**：先下载 `正式版/`，再按需下载 `依赖包/`
- **后续更新**：通常只需要重新下载 `正式版/`
- **只有在缺少运行库时**，才需要再用到 `依赖包/`

## 首次使用方式

1. 先下载或解压 `正式版/`
2. **优先运行 `正式版\Start.bat`**
3. 若提示缺少运行库，再下载或解压 `依赖包/`，运行 `依赖包\Install-Runtime.bat`
4. 安装完后再打开 `正式版\Start.bat` 或 `read-one.exe`

## 后续更新与清理

- 这台机器一旦装好运行库，后续一般只保留 `正式版/` 即可
- `依赖包/` 在安装完成后通常可以删除，需要重装系统或换新机器时再重新下载
- 如果只是升级 read-one 版本，直接替换 `正式版/` 内容即可

## 为什么默认从 Start.bat 启动

- `Start.bat` 会先自检 `.NET Framework 4.7.2`
- 如果缺少运行库，它会提示你去运行 `依赖包\Install-Runtime.bat`
- 某些机器若直接双击 `read-one.exe`，可能会因为系统缺运行库而来不及弹出提示

## 主要功能

- 书架、最近阅读、章节目录、书签  
- 单行 / 多行模式，主题、字号、行距  
- 听书语速调节  
- 启动续读、自动存进度  
- AI 助手（需自行填写 DeepSeek API Key）  
- B 站视频小窗：整体缩小视野、滚轮纵向浏览、快捷键拖动、老板键联动暂停  
- 听书 / 小窗时可静音指定扬声器，防外放
