# 使用说明

## 下载与安装

1. 打开 [Releases](https://github.com/xuanmossdx/read-one/releases)，下载最新主程序压缩包并解压  
2. 双击 `Start.bat`（推荐）或主程序启动  
3. 若提示缺少运行环境，再下载同页面的「运行库」包并按其中说明安装  

也可使用仓库首页的一键安装命令（Windows 自带 PowerShell）。

程序为便携方式：解压即用，进度与设置保存在程序所在目录。

## 更新

- 程序联网时会定期检查本仓库是否有新版本；有更新时会提示并自动安装重启  
- 也可在设置「更新」页手动检查  
- 或从 Releases / 一键安装覆盖程序文件；**不要删除**自己的进度与书籍  
- 运行库只需在电脑缺环境时装一次  

若需完全断网使用，可在设置中开启「关闭全部外网」（更新、B 站、AI 将不可用）。
