# 文档

## 下载与启动说明

- 第一次安装：先解压 `正式版/`，运行 `正式版\Start.bat`
- 如果 `Start.bat` 提示缺运行库，再运行 `依赖包\Install-Runtime.bat`
- 运行库装好后，后续通常只需保留 `正式版/`
- `依赖包/` 安装完成后一般可以删除
