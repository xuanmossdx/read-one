# 版本更新日志

## 1.3.0

- 自动更新加固：更新包必须通过 SHA256 校验，并拒绝包含非法路径的压缩包，防篡改与目录穿越。
- 日志自动轮转：`log.txt` 超过 2 MB 自动滚动为 `log.txt.bak`，只保留最近一份，长期听书不再让目录无限变大。
- 热键失败可见：快捷键被其它软件占用时，托盘气泡会提示具体失败的键位，不再静默失效。
- AI 密钥改用 Windows DPAPI 加密保存（仅当前系统账号可解），旧密文首次加载自动迁移，无需重填。
- 设置页「插件」页与主窗「附页」菜单入口暂时隐藏（插件内容尚未发布）。
- 内部整理与若干修复，行为不变。
