# 版本更新日志

## 1.5.0

- 新增插件中心：设置 → 插件 可查看、安装、更新与卸载插件（插件按来源单独分发）；「关闭外网」同样会阻止插件的联网功能。
- 修复多行阅读：段首折行时滚动后底部偶发出现一行空白、再次滚动才补出的问题。

## 1.4.0

- 目录新增搜索：输入章节号可直接定位（`102`、`一百一十二` 都行），也可只写章节名的一部分实时筛选；回车或双击直接跳转。
- 书架按文件夹分页签：不同子文件夹各自成页签，不再混在一个列表；未读的书按文件时间排序，新下载的书排在前面。
- 自动更新后弹窗展示更新内容：更新完成重启后弹出本次更新说明。
- 修复个别情况下更新后程序文件未真正替换（版本号变了但仍是旧程序）的问题：更新收尾对主程序复制增加重试。
- 修复 Windows 10 通知中心里应用名显示为 Microsoft.Explorer.Notification… 的问题：通知名称显示 read-one。
- 修复部分电脑上个别汉字（如「关于」的「关」）被压窄变形的问题：窗口字体改用微软雅黑；同时优化高缩放下的文字渲染。
- 设置页选中标签改为加粗 + 下划线、文字保持深色，选中状态更清晰。

## 1.3.2

- 修复部分网络环境下手动/自动检查更新失败的问题：GitHub API 被限流时自动改用网页备用通道，下载直链优先走可加速镜像。
- 修复更新后插件底座 DLL 未被同步覆盖、插件加载报错的问题。

## 1.3.1

- 修复自动更新重启后残留命令行窗口的问题：更新收尾全程无窗口执行，并直接拉起主程序。

## 1.3.0

- 自动更新加固：更新包必须通过 SHA256 校验（Release 资产或 `.sha256` 文件），并拒绝含非法路径的压缩包，防篡改与目录穿越。
- 日志自动轮转：`log.txt` 超过 2 MB 自动滚动为 `log.txt.bak`，只保留最近一份，长期听书不再让目录无限变大。
- 热键失败可见：快捷键被其它软件占用时，托盘气泡会提示具体失败的键位（并在日志留档），不再静默失效。
- AI 密钥改用 Windows DPAPI 加密保存（仅当前系统账号可解），旧密文首次加载自动迁移，无需重填。
- 设置页「插件」页与主窗「附页」菜单入口暂时隐藏（插件内容尚未发布，宿主代码保留）；已装插件与存档不受影响。
- 内部整理：主窗口按功能拆分到独立文件，章节识别与书签/历史查询各自独立成模块，行为不变。

### 1.3.0 同时包含（原「未发布」批次）

- 挂机游戏插件宿主：契约 DLL 隔离、单一运行调度、透明游戏窗、按文件夹安装/卸载（默认保留存档）。三款插件内容暂未发布，入口已隐藏。
- 删除设置页「高级功能」页：窗口图标/标题移到「样式」页「外观」组继续可改；代理设置界面随页删除，DB 中既有代理配置保留供 AI 与下载读取。
- 「样式」页新增外观预设四档（默认/文档/笔记/日程，通用图标与中性名称），也可自行选图改名。
- 删除日间/夜间/护眼三档主题预设；字色/底色仍可在「样式」页自定义，字号/行距菜单保留。
- 更换软件图标（透明背景打开书本），覆盖 exe/快捷方式、窗口左上角、任务栏与托盘。

## 1.2.0

- 优化缩进滑块：每滑动一格就是一个中文字符（1 格 = 1 个汉字宽）。
- 优化隐秘性：不会在开始菜单创建图标；启动时还会清理旧版本已创建的同名快捷方式。
- 新增菜单自定义：加入菜单自定义功能，可根据自己的需求定制菜单（设置页「菜单」页可勾选主窗口右键菜单的一级条目显隐，保存后立即生效）。

## 1.1.2

- 托盘新增「重置位置」：阅读主窗回到主显示器工作区左下角，边框高亮 + 透明度闪 3 次指引。
- 一键安装 / 自动更新：优先 GitHub API 资源链下载；校验真 zip；失败持续重试；失败提示含 QQ 群。

## 1.1.1

- 安装与自动更新：多镜像与 GitHub 并行竞速，带超时；连不上会明确提示。
