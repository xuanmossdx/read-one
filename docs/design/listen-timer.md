# 听书定时关闭

## 业务背景

听书（SAPI 朗读）可能长时间外放。用户需要在一段时间后自动停止，避免忘记关朗读。

## 核心逻辑

1. 主窗右键「听书 → 定时关闭」可选：关闭 / 15 / 30 / 60 分钟。
2. 选项写入 `ConfigUtil.ListenTimerMinutes`（仅允许 0/15/30/60）并持久化。
3. 开始听书（`StartSpeakMod`）时若分钟数 > 0，启动/重置 `DispatcherTimer`。
4. 到期调用 `CloseVoice()` 停止朗读并恢复扬声器静音状态。
5. 用户手动停止听书时取消定时器；配置中的分钟数保留，下次开听书仍按上次选择计时。
6. 老板键隐藏时定时器继续走，到点仍关闭（避免外放）。
7. 定时到点 `CloseVoice()` 停止听书；听书操作台可仍保持打开（见 `listen-console.md`）。

## 关联影响

- 依赖现有听书启停：`StartSpeakMod` / `StopSpeakMod` / `CloseVoice`
- 与扬声器静音联动：停听书时走既有 `SpeakerMuteController`

## 边界与异常

| 场景 | 处理 |
|------|------|
| 选「关闭」 | 取消定时器，分钟数置 0 |
| 听书未开始时改时长 | 只改配置；真正开听书后再计时 |
| 非法分钟数 | `ClampListenTimerMinutes` 归 0 |

## 外部依赖

无。
