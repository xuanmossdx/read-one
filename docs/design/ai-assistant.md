# AI 助手

read-one 可通过 DeepSeek 官方 API 提供聊天与联网搜索（需联网，并自行准备 API Key）。

## 怎么用

1. 右键菜单打开「AI 助手」，进入双行对话：上行看回复，下行输入，Enter 发送  
2. 在设置里打开「AI 助手」页（或右键「AI 设置…」）填写 API Key，并选择模型与人设  

## 常用选项

- **API Key**：在 [DeepSeek 开放平台](https://platform.deepseek.com/) 申请  
- **模型**：DeepSeek V4（Flash / Pro）  
- **深度思考 / 联网搜索**：按需开启  
- **人设预设**：可选用内置或自建人设  

## 注意

- 未填写 Key 时无法发送，按提示去设置即可  
- 使用老板键隐藏窗口时，进行中的 AI 请求会取消  
- 需要本机能够访问 DeepSeek 服务（也可在设置中配置系统代理）
