# 章节目录识别

## 业务背景与存在意义

TXT / EPUB / MOBI 打开后都转为纯文本按行识别标题生成 TOC（EPUB/MOBI 无单独 NCX 目录管道）。识别过松会把正文收进目录；过严会漏章。

## 核心逻辑

入口：`Util.CheckIsChapterTitle`（`BindChapter` / `RebuildChapterList`）。

1. 去首尾空白；长度 2–64；含对话引号则否。
2. 去掉句末 `！？。.…～` 再匹配。
3. 匹配形态：
   - `第` + 数字 + **`章节回话节`** + 可选分隔符 + 标题（**含「节」**，蛊真人等）
   - 允许无分隔符（如「第一章您的存在」）
   - `第N集` / `Chapter N` / `第N卷`
   - `序章/序言/楔子/…` 以及 **`序：标题`**
4. 正文排除：含 `。`/`；`，或纯「第…幕」；**标题中的 `，`/`、` 允许**（如「天有不测风云，炼蛊别具艰辛」）。

## 与其它模块的关联

- `Util.GetFileString`：txt 直读；epub→`EpubReader.ToPlainText`；mobi→`MobiUtils`；之后同一套 `BindChapter` 逐行识别。
- `MainWindow.BindChapter`：仅 `readFlag==0`（本地书）建 TOC。

## 边界与异常

| 场景 | 处理 |
|------|------|
| 蛊真人 `第三百六十八节：方源、巨阳…` | 认「节」；顿号/逗号保留 |
| `第十节：…，…` 标题含逗号 | 不因逗号判正文 |
| `序：不是走向成功，就是走向毁灭` | 认「序：」 |
| `第23章 你是我的人！` | Trim 感叹号 |
| 「第一幕。」 | 不认幕 |
| 正文「走进了第一章…」 | 不以「第」开头 → 排除 |

## 外部依赖

无。以常见网文标题形态 + 单测覆盖（含蛊真人样例）。
