# 扬声器静音（听书 / B 站小窗）

## 业务背景

听书（SAPI）与 B 站小窗（WebView2）都走**系统默认播放设备**，音量跟随**系统音量**（无软件内独立总音量）。若默认或旁路仍会打到扬声器，办公场景容易外放。需要在听书或打开视频小窗时，对用户指定的「扬声器」端点做**系统级静音**；耳机等其它设备保持可用。

## 核心逻辑

1. 设置项（默认开启）：
   - `MuteSpeakersFlag`：听书 / B 站小窗期间是否静音扬声器。
   - `SpeakerDeviceId`：视为扬声器的输出设备 Id；空则自动识别。
2. 自动识别：枚举活动渲染端点，名称含「扬声器 / 喇叭 / speaker」且不像耳机/蓝牙耳麦时优先；否则回退默认设备。
3. 会话挂钩：
   - 听书：`StartSpeakMod` → 静音；`StopSpeakMod` → 若小窗未开则恢复。
   - B 站小窗：打开 → 静音；关闭 → 若未在听书则恢复。
4. 仅恢复**本程序静音前未静音**的设备；若用户本来就静音扬声器，退出时不擅自取消静音。
5. 主窗关闭 / 进程退出时强制尝试恢复。

## 关联影响

- 与听书、B 站小窗共用一套 `SpeakerMuteController`。
- 设置页「其它」可勾选开关并选择具体扬声器设备。
- 若误把耳机或唯一默认设备标成扬声器，听书/视频可能无声；应改选真正的外放设备或关闭该选项。

## 边界与异常

| 场景 | 处理 |
|------|------|
| 无输出设备 / COM 失败 | 记日志，不抛到 UI |
| 配置的设备已拔出 | 回退自动识别 |
| 听书换句时内部 Cancel+Speak | 不按句恢复，按听书会话 |
| 老板键隐藏小窗未关闭 | 保持静音（可能仍在播） |
| 关闭「扬声器静音」并保存 | 立即恢复本程序改过的静音 |

## 外部依赖

- Windows Core Audio（`IMMDeviceEnumerator` / `IAudioEndpointVolume`），无额外 NuGet。
