# 数据与进度

程序会把阅读进度、书签、设置等保存在 **与 `read-one.exe` 同一目录**。把整个文件夹拷走，进度一般会一起带走。

## 更新版本时

只替换程序相关文件（如 `read-one.exe`、依赖 dll 等），**不要删掉**目录里原有的数据与书籍，以免丢进度。

## 书籍放哪

可以把书放在程序目录，或常用的书籍文件夹（如 `books`、`txt小说`、`txt留档` 等），书架会自动扫描。

## 说明

- 书籍若放在程序目录以外的盘符路径，换电脑或改盘符后，偶发可能对不上进度；多数情况下仍可按文件内容找回。  
- 本软件为本地使用，阅读本身不依赖账号或会员服务。AI 功能需自行配置第三方 API。
