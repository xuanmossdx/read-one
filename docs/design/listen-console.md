# 听书操作台小窗

## 业务背景

听书（SAPI）进行中需要独立透明操作台：语速、行跳转、暂停/继续，而不必每次打开主窗右键菜单。与阅读窗、B 站小窗一样支持老板键伴生隐藏与移开藏控件。

## 核心逻辑

1. 右键「听书 → 打开操作台 / 关闭操作台」控制 `ListenConsoleWindow`（打开时不自动开始听书）。
2. 底栏按钮：语速±、上一行、**播放/暂停**、下一行、关闭操作台（**WPF Path 自绘图标**，不依赖字体字形）。
   - **未听书**：中间键为三角「开始播放」，等价 Alt+V 开读（`ListenConsoleStartSpeak`）。
   - **听书中**：中间键暂停/继续（Alt+P）；整段停止仍用 Alt+V 或菜单「开始/停止朗读」。
3. 背景与主阅读窗一致（`ThemeService.CreateBackgroundBrush` + `StyleBackGroundAtpa`）；图标 Fill/Stroke 的 Alpha = `StyleFontAtpa`。
4. **移开藏控件**：与「移开藏字」同配置；隐藏时 `gdToolbar.Opacity=0` 且 `IsHitTestVisible=false`，保留 `hitPlate`；移出约 180ms 后隐藏。显示条件必须同时满足：**鼠标在操作台内** +（若配置了移入显示热键）**按住该热键**；禁止只按热键、未移入就显示。
5. **老板键**：藏主窗时一并藏操作台；**听书不暂停、不停止**（仅藏 UI）。
6. **屏同步**：读完当前屏可见文字 → `BeginInvoke` 回 UI → 翻下一屏（或同书下一章）再朗读；手动上一行/下一行或翻页前 `PrepareListenLineJump()` 取消当前句再读新屏。
7. **播放/暂停**：未听书时操作台中间键可直接开读；听书中由菜单、**Alt+P**、操作台按钮暂停/继续；续播从 SAPI 暂停位置继续。

## 听书翻页与外观

- **按阅读窗当前屏推进（不是小说 txt 物理行）**：多行朗读本屏可见折行拼起来的文字，说完后按可视行前进一屏（等同 PgDn；末屏不足一页则进下一物理行）。单行朗读窗口里那一行后换下一行。阅读窗隐藏时仍继续。
- **长段落**：一段物理行会折成多屏，只读当前屏上那一块，窗跟着翻。
- **章末**：绑屏不跨过下一章标题；本章最后一屏说完后跳到**同书目录下一章**开头继续听。无目录则整本当一章，翻到书末结束。章与章之间不打开下一本文件。
- **空行/链接**：本屏无可朗读文字时按同一套可见屏算法再推一屏。
- **暂停/继续**：`Pause`/`Resume` 断点续播；若引擎 Pause 后语句已死，则**本屏**重开，不跳屏。
- **无感翻页（音频优先）**：多屏文字拼成**单段连续朗读**（`ListenChunkBuilder` + `SpeakContinuousChunk`），SAPI 只开一次口；屏界标记在**本屏开读**时触发，显示同步到 `SpokeLine/SpokePy`（正在读的屏），不用 `DisplayLine`（下一屏），避免显示超前朗读一页。朗读文本保留原文标点（句间/段间自然停顿）；屏与屏之间**不**补标点，避免长段折屏时在句中停顿。块完成回调**必须回 UI 线程**再拼下一屏；若已 Pause，worker 启动下一块时跳过（不清 `pauseDepth`）。
- **自动化测试**：`RunListenTwoChapterE2E` 真实 SAPI 两章 6 屏应在 **1 次 Speak** 内完成，目标 10s、上限 30s。
- **暂停/继续**：`Pause`/`Resume` 用 worker 上同步 `Invoke`，可立即打断当前句；续播从 SAPI 断点继续，不自动整屏重开。
- **字色**：听书不使用高亮红字。
- **手动翻页/滚轮浏览**：只改显示位置（`currentLine`/`spMutPy`），**不** `Cancel`、不重启朗读；朗读锚点（`listenAnchorLine`/`listenAnchorPy`）不变。
- **自动翻页**：本屏读完 → 按**朗读锚点**算下一屏 → 把显示**同步跳回**朗读位置再继续读（不是从你手动翻到的页往下走）。
- **操作台上一行/下一行**：仍视为刻意跳转，会 `PrepareListenLineJump` 并同步锚点。
- **回调世代**：`listenSpeakToken` 丢弃过期完成回调。
- **窗位**：允许负坐标（副屏）；恢复时夹到虚拟桌面。

## 操作台显隐

- 与主阅读窗同一套「移开藏字 / 移入显示」配置。
- 显示：鼠标在操作台内 +（若配置）按住移入显示热键。
- 隐藏：`MouseLeave` 后延迟收起（与主窗一致）。
- 注意：听书时主阅读窗也曾因 `autoMod==0` 判断导致移走不藏字，已改为听书模式下同样移开藏字。

| 默认 | 作用 |
|------|------|
| Alt+V | 开始/停止听书（整段会话；藏窗后仍可用） |
| Alt+P | 暂停/继续（须已在听书中；藏窗后仍可用） |

## 关联影响

- 依赖 Windows SAPI（`Constants.ReadMod=1`）
- `InitStyle` 结束时 `SyncListenConsoleTheme()`
- 窗口位置持久化：`ListenConsoleWidth/Height/Left/Top`

## 边界与异常

| 场景 | 处理 |
|------|------|
| 手动翻页后无声 | 浏览时不 Cancel；若需从朗读位重开用暂停/继续或操作台行跳 |
| 听书中手动翻页 | 朗读继续；自动翻页按朗读锚点推进并拉回显示 |
| 未开始听书点中间键 | 直接开始听书 |
| 未开始听书点行跳 | 提示先开始听书 |
| 老板键隐藏 | 藏操作台；SAPI 继续；**Alt+P / Alt+V 仍响应**（不要求主窗可见） |
| 关闭操作台 | 不停听书 |
| 定时关闭听书 | 仍 `CloseVoice()`；操作台可仍打开 |
| 第一屏后整窗卡死 | STA 完成回调与 Speak 内 Cancel 禁止互相同步 Invoke；回归测试：回调里 `ui.Invoke(Speak下一屏)` 必须连续 3 次 complete |
| 书末 | `ShowMsg(">>> 本次阅读已经结束 <<<")`，不自动开下一本 |

## 外部依赖
